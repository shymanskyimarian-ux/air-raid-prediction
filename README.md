# Air Raid Alerts Prediction in Ukraine

Цей проєкт представляє собою аналітичну систему та пайплайн для прогнозування повітряних тривог в Україні на основі історичних даних. Використовуючи статистичні методи часових рядів (ARIMA) та імовірнісний аналіз, модель прогнозує найімовірніший час, регіон, тривалість та тип загрози (БПЛА, крилаті ракети, балістика тощо) на найближчі 7 днів.

## Як це відбувається?

*   **Очищення та агрегація даних:** Автоматична обробка сирих логів тривог, заповнення пропущених днів (затишшя) нулями для забезпечення безперервності часових рядів.
*   **Прогнозування часових рядів (ARIMA):** Побудова базового тренду кількості тривог на горизонт в 1 тиждень.
*   **Класифікація загроз:** Визначення типу застосованого озброєння на основі географії області та тривалості тривоги.
*   **Візуалізація (Gantt Chart):** Генерація наочного таймлайну (діаграми Ганта), що відображає прогнозовані часові вікна небезпеки для кожної області з кольоровим кодуванням типу загрози.

## Використовуємо:

*   **Мова програмування:** Python 3.x
*   **Обробка даних:** Pandas
*   **Машинне навчання / Статистика:** Statsmodels (ARIMA)
*   **Візуалізація:** Matplotlib, Seaborn
